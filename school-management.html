About This Project

The Excel Heights School Management System (EHS SMS) is a full-featured, production-ready school management platform tailored for primary to Junior High School (JHS) levels. Built with a modern tech stack (Next.js 16 App Router, React 19, Tailwind CSS 4, and Supabase), the system provides an all-in-one digital ecosystem to streamline school administration, finances, academics, and communication.

Key Features

  • Role-Based Dashboards — Distinct, secure interfaces tailored for 8 specific roles: Admin, Bursar, Teacher, Parent, Headmaster, Proprietor, HR, and Job Applicants.
  • Comprehensive Student & Academic Management — Streamlined student enrollment with automated STU-XXXX ID generation, daily attendance tracking, digital lesson plans, and detailed disciplinary logs.
  • Automated JHS Grading System — Digital gradebooks allowing teachers to input Continuous Assessment (30%) and Exam scores (70%). Database triggers automatically compute totals, remarks, and letter grades.
  • Robust Financial & Fee Tracking — Configurable fee breakdowns by class (tuition, labs, PTA, etc.). Built-in invoicing, instant payment recording, overpayment rollover protection, and real-time outstanding balance tracking.
  • Online Public Admissions — A public-facing portal where prospective students can apply, upload documents, and securely track their application status using their application number and guardian phone.
  • Smart Academic Calendar & Timetables — Year-aware date comparison that automatically transitions between academic terms and "Vacation Break" modes across all dashboards. Includes an interactive, grid-based class timetable builder.
  • HR & Applicant Workflow — Full applicant tracking pipeline (from Pending to Shortlisted/Interviewed) alongside comprehensive 5-star performance evaluations for current staff.
  • Mobile-Ready & Accessible — Installable as a Progressive Web App (PWA) on mobile devices, complete with full offline caching and an Android Capacitor build. Designed with strict accessibility (ARIA) guidelines and custom UI confirmations.

Technologies Used

  • Frontend: Next.js 16 (App Router) & React 19 for a modern, server-rendered architecture.
  • Styling: Tailwind CSS 4 & Lucide Icons for a clean, responsive, and consistent UI.
  • Database & Auth: Supabase (PostgreSQL with Row Level Security) for secure, scalable data storage and authentication.
  • Analytics & Reporting: Recharts for live financial insights; jsPDF for downloading official report cards, fee receipts, and bulk invoices.

Project Impact

EHS SMS delivers a modern, efficient, and secure alternative to traditional school administration methods. By digitizing attendance, grading, fee tracking, and admissions, the system dramatically reduces manual paperwork and administrative overhead while improving accuracy and transparency. The platform is production-ready and scalable, serving as a complete digital backbone for any primary or JHS institution.
